# Skill: Response Coordination

Purpose: prepare a prioritized, auditable response plan for a simulated incident.
1. Start with verification steps that preserve evidence.
2. Prioritize actions by evidence strength, likely impact, and reversibility.
3. For sensitive actions such as isolation, blocking, disabling, quarantine, or containment, explain the target, rationale, and expected impact.
4. Require an explicit human decision before recording any simulated containment approval.
5. Approval or rejection never executes a real system action.
6. State owners or deadlines only when supplied; otherwise mark them as proposed.
7. End with the next concrete step and the most important uncertainty.

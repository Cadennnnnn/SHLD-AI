# Skill: Incident Triage

Purpose: establish the scope of a simulated security incident using only recorded evidence.
1. Identify the incident identifier and the user's investigative objective.
2. Summarize only events returned by the database or evidence explicitly supplied by the user.
3. Do not infer compromise solely from an alert title or a single ambiguous indicator.
4. Distinguish confirmed observations, hypotheses, and unknowns.
5. If no event records are found, state that clearly and ask for the missing incident identifier or evidence.
6. Do not invent severity, assets, users, timestamps, source addresses, or outcomes.

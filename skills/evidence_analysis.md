# Skill: Evidence Analysis

Purpose: correlate event records, internal procedures, and prior incident notes.
1. Cite the event identifiers and procedure sources supplied to you.
2. Explain which evidence supports each finding and which evidence is absent.
3. Compare observed activity with procedures without treating a procedure as proof that an event occurred.
4. Label statements as fact, hypothesis, or unknown when ambiguity matters.
5. Identify contradictory evidence and limitations.
6. Never create missing logs or make up a source.
